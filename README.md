# Designer Improved for Hearts of Iron 4
Ce mod vise à améliorer le concepteur d'avions dans *Hearts of Iron IV* en introduisant de nouvelles fonctionnalités et modules pour une expérience de jeu enrichie. Inspiré de deux mods précédents très appréciés, il fusionne leurs idées principales avec des ajouts uniques pour offrir un concepteur d'avions encore plus complet et personnalisable.

## Inspirations principales
- **Air Designer improved** ([voir sur Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2884019213))
- **Reworked Air Designer** ([voir sur Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=2948174914&searchtext=air+designer))

Ces deux mods ont été des sources majeures d'inspiration, et ce projet reprend leurs meilleures idées tout en ajoutant des innovations pour créer une expérience unique.

## Fonctionnalités principales
- **Nouveaux modules ajoutés** :
  - Options supplémentaires pour les types d'ailes, les fuselages et les moteurs.
  - Ajout de systèmes avancés, tels que le blindage, l'armement et l'électronique.
  
- **Extension des possibilités de personnalisation** :
  - Inclut des designs emblématiques de la Seconde Guerre mondiale.
  - Permet des configurations fictives basées sur des concepts réalistes.

- **Fusion des caractéristiques** :
  - Combine les meilleures idées des mods mentionnés.
  - Ajoute des fonctionnalités uniques pour la domination aérienne, le bombardement stratégique et le support au sol.

## Compatibilité
Ce mod a été testé sur les versions suivantes de *Hearts of Iron IV* :
- **1.13.7**
- **1.14**

## Installation
1. Téléchargez les fichiers du mod depuis GitHub ou Steam Workshop.
2. Placez-les dans le dossier `mod` de votre installation de HOI4.
3. Activez le mod dans le launcher du jeu avant de commencer une partie.
